## Overview

Apex Research Agent Working Style Preview is a browser-based interface for showing the current working state of Apex Research Agent. It gives users a visual way to follow the agent while it is active.

Alongside the status display, the preview provides a dedicated area for examining and comparing different agent working styles. The project is implemented with HTML and is designed for reviewing both Apex Research Agent activity and the ways that activity is presented.
